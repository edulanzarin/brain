# 2026-07-20

## Foco do dia

Construir o [[Navedesk]] do zero — sistema de chamados interno da Navecon,
rodando em Docker na porta 4001 para toda a rede acessar.

## Feito / aprendido

- Sistema completo no ar: chamados com prioridade e SLA, anexos, comentários
  com nota interna, linha do tempo, notificações in-app, avaliação, painel de
  indicadores e área de administração (usuários, setores, categorias, config).
- Três perfis (TI, Gestor, Usuário) com as regras de visibilidade num arquivo
  só; auto-cadastro restrito ao domínio `@navecon.net.br`.
- Visual reusado do [[Questor BI]] pelo MOC [[Design]] — não redesenhei nada do
  zero, e o resultado já nasceu "da mesma família".
- Deploy num comando: `docker compose up -d --build` aplica migration e seed
  sozinho, via container de migração que roda e encerra.
- Validei ponta a ponta com navegador de verdade (não só typecheck/build) — e
  foi exatamente aí que apareceram os três defeitos do dia: ícone cruzando a
  fronteira server/client, `@layer` faltando no CSS e o formulário sendo
  resetado depois de um erro de validação.
- Depois virei para o [[Cofre Digital]] e passei o mesmo pente do [[Design]]:
  os 24 `alert()` viraram toast (e as ações de sucesso passaram a confirmar —
  antes o app só falava para reclamar), o carregamento em bloco cinza virou
  esqueleto com a forma do conteúdo, e busca/filtro foram para a URL. A página
  de certificados chegava a *limpar* a query string, o oposto do princípio 4.
- O módulo de alvarás que estava sem commit entrou antes de tudo, para ter
  rede de segurança.
